PROMPT MAESTRO — INTEGRACIÓN DE OPENAI EN PRYSM

Quiero integrar OpenAI en PRYSM para convertir el sistema actual en un analizador de imagen y estilo realmente personalizado.

IMPORTANTE:
NO MODIFIQUES EL DISEÑO VISUAL ACTUAL.
NO CAMBIES LA LANDING.
NO CAMBIES EL DISEÑO DEL QUIZ.
NO CAMBIES LA ESTRUCTURA VISUAL DEL REPORTE.
NO CAMBIES LA ESTRUCTURA VISUAL DEL PDF.
NO ELIMINES FUNCIONALIDADES QUE YA FUNCIONAN.

El objetivo es cambiar principalmente EL MOTOR DE ANÁLISIS, no la interfaz.

==================================================
1. OBJETIVO PRINCIPAL
==================================================

Actualmente PRYSM utiliza reglas fijas para determinar temporada, colores y recomendaciones.

Quiero reemplazar esa lógica fija por un análisis inteligente utilizando OpenAI.

OpenAI debe analizar conjuntamente:

- Las fotografías del usuario.
- Las respuestas completas del test.
- El análisis colorimétrico existente de Canvas.
- El tono de piel indicado en Q2.
- La silueta indicada en Q3.
- El presupuesto de Q4.
- Los colores existentes del clóset de Q5.
- Las prendas existentes de Q6.
- El metal de Q7.
- El estilo de Q8.
- Las ocasiones de Q9.
- El look/arquetipo de referencia de Q10.

NO quiero que una sola respuesta determine todo el resultado.

El resultado debe ser la combinación de TODA la información disponible.

5. TEMPORADA Y PALETA
==================================================

El sistema debe poder producir diferentes resultados.

Por ejemplo:

- Primavera
- Verano
- Otoño
- Invierno

Y sus subcategorías si PRYSM decide utilizarlas.

La temporada NO debe depender solamente de:

undertone + depth

ni de una condición hardcodeada.

La IA debe evaluar toda la evidencia disponible.

Debe devolver:

season
season_name
confidence
reason

Ejemplo:

{
  "season": {
    "id": "spring_warm",
    "name": "Primavera Cálida",
    "confidence": 0.87,
    "reason": "..."
  }
}

La explicación debe ser específica para esa persona.

==================================================

No utilizar siempre la misma paleta.

Separar:

- colores protagonistas
- colores secundarios
- neutros
- acentos
- colores recomendados para prendas superiores
- colores recomendados para prendas inferiores
- colores recomendados para accesorios
- colores a evitar o utilizar con moderación

Cada color debe tener:

- nombre
- HEX
- explicación breve

Ejemplo:

  "hex": "#..."
  "reason": "..."
}

No inventar colores arbitrarios que contradigan la colorimetría.
