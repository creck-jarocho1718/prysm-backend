Construye un PDF editorial premium de 7 páginas para PRYSM — una plataforma de asesoría de imagen personal. Este PDF es el informe final que recibe la clienta después de completar el quiz y subir sus fotos.

DATOS QUE RECIBES (usar estos, nunca inventar)
Cuando la clienta termina el quiz, el sistema genera estos datos automáticamente:

name: nombre de la clienta (string)
season.name: temporada de color (ej: "Otoño Profundo", "Verano Suave", "Invierno Brillante", etc.)
season.name_en: nombre en inglés (ej: "Deep Autumn", "Soft Summer")
season.temperature: warm / cool / neutral
season.depth: light / medium / deep
season.description: descripción de la temporada (1-2 oraciones)
palette.protagonist: array de 3 hex codes de colores protagonistas
palette.secondary: array de 2 hex codes de colores secundarios
palette.neutral: array de 2 hex codes de colores neutrales
palette.accent: array de 2 hex codes de colores de acento
palette.avoid: array de 4-5 hex codes de colores a evitar
silhouette: tipo de cuerpo (ej: "Reloj de arena", "Triángulo invertido", "Rectangular")
silhouette_tips.do: array de 4 tips de qué favoreces
silhouette_tips.dont: array de 4 tips de qué evitar
fabrics: array de 5 telas recomendadas
hair_colors: array de 3 hex codes de tonos de cabello
hair_cuts: array de 4 cortes recomendados
face_shape: forma de rostro (ej: "Ovalada", "Cuadrada", "Redonda")
outfits: objeto con 4 looks {casual, office, date, travel}, cada uno tiene {name, pieces: [], colors: []}
jewelry: {metal, tones: [], avoid: [], styles: []}
bags: array de 3 tipos de bolso
prysmScore: número del 8.0 al 9.9
skin.baseColor: hex code del color de piel detectado
skin.undertone: warm / cool / neutral
skin.depth: light / medium / deep
skin.contrast: high / medium / low
photoUrl: URL de la foto que subió la clienta (para poner en la cover)

CÓMO GENERAR EL PDF
Usa Playwright (Node.js) para renderizar el HTML y convertirlo a PDF:

javascript


const { chromium } = require('playwright');
async function generatePDF(data, outputPath) {
  const html = buildHTML(data); // Template literal con los datos inyectados
  const browser = await chromium.launch({ headless: true });
  const page = await browser.newPage();
  await page.setContent(html, { waitUntil: 'networkidle' });
  await page.pdf({
    path: outputPath,
    format: 'A4',
    printBackground: true,
    margin: { top: 0, right: 0, bottom: 0, left: 0 }
  });
  await browser.close();
}
REGLAS CRÍTICAS
1.
Usar los datos reales, nunca inventar. Si un dato no viene del análisis, poner "No disponible" — no inventar colores, nombres o descripciones.

2.
La foto de la clienta va en la cover. Siempre. Si no hay foto, usar un placeholder ovalado con las iniciales.

3.
El PDF debe tener 7 páginas exactas. No 6, no 8. Si el contenido no llena una página, agregar espacio o repetir elementos.

4.
Sin marketing. Este PDF lo recibe la clienta como documento profesional. Cero promociones, cero links, cero llamados a acción.

5.
Los hex codes deben ser exactos. Copiarlos tal cual vienen del sistema, sin modificar.

6.
Los outfits deben usar los colores de la paleta. Cada look debe mostrar los colores correctos de la clienta, no colores genéricos.
